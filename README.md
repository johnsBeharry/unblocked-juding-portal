# UNBLOCKED Judge Portal

Standalone judge portal for the UNBLOCKED poster review workflow.

## Files

- `index.html` - portal entry page for GitHub Pages or direct browser preview
- `judges.html` - same portal kept under the original filename
- `styles.css` - portal styling
- `script.js` - portal interactions, review data, ratings, finalist logic, and reset flow

Open `index.html` in a browser to start the portal.
